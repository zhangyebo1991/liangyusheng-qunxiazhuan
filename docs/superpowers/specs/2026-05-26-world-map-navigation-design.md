# 大地图功能设计规格书 (World Map & Auto-Movement)

## 1. 功能概述
在现有大地图系统基础上，新增全屏地图界面。玩家可通过 [M] 键开启，在大地图上通过点击目的地实现自动寻路移动，并支持 WASD 无缝打断。

## 2. 视觉与 UI 设计 (UI/UX)
*   **整体风格**：全屏古风画轴设计，采用宣纸纹理背景。
*   **交互反馈**：
    *   **点击反馈**：点击位置产生水墨扩散动效（Ink Ripple）。
    *   **当前位置**：角色头像或特制图标在地图上闪烁或带呼吸灯效果。
    *   **路径显示**：自动移动时，地面显示淡淡的水墨虚线路径。
*   **布局**：
    *   **中心区**：展示江湖各区域、地标、路线。
    *   **边缘**：古风边框，角落带有“江湖全图”印章。

## 3. 技术实现方案

### 3.1 导航系统 (Pathfinding)
*   **核心技术**：使用 Godot 的 `AStar2D` 算法。
*   **网格划分**：将 4000x3000 的大地图划分为 40x40 的网格点。
*   **阻挡逻辑**：
    *   根据 `world_map_config.json` 中的 `regions` 边界初始化可通行区域。
    *   支持“动态拦截”：通过代码禁用特定网格点（如：未解锁区域、剧情封锁点）。

### 3.2 移动与打断逻辑
*   **状态管理**：引入 `auto_moving` 状态位。
*   **点击触发**：在 `world_map_screen.gd` 监听鼠标点击，计算 AStar 路径并推送到 `player_controller`。
*   **打断机制**：
    *   在 `_physics_process` 中优先检测 WASD 输入。
    *   若检测到非零的 `input_vector`，立即清除 AStar 路径缓存并将 `auto_moving` 设为 `false`。

### 3.3 场景转换
*   **入口**：全局监听 [M] 键。若当前不在大地图，则保存当前场景状态并切换。
*   **保持一致性**：由于大地图是全屏场景，需确保 `GameState` 实时记录玩家坐标，以便在退出地图场景时位置正确。

## 4. 验收标准
1.  [ ] 按 [M] 键能流畅切换至全屏大地图 UI。
2.  [ ] 鼠标点击地图任意合法点，主角自动绕过阻碍物移动。
3.  [ ] 移动过程中按下 WASD 任意键，主角立即转为手动控制。
4.  [ ] 点击不可通行区域或被拦截区域，系统给出提示且不移动。
5.  [ ] UI 表现符合“江湖画卷”的视觉要求。

## 5. 潜在风险与对策
*   **性能**：大地图网格过多可能导致寻路计算延迟。**对策**：采用分层寻路或优化网格密度。
*   **坐标转换**：UI 点击位置与世界坐标的映射。**对策**：使用 `get_global_mouse_position()` 进行精确换算。
