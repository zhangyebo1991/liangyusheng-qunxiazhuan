# 下一阶段地图与剧情生产管线需求

## 核心判断

目前 MVP 已经把移动、任务、对话、战斗、存档、事件等基础闭环跑通了，这一阶段的价值很明确。

但下一阶段如果继续往现有小地图里塞剧情，会很难推进。现在剧情和设定内容已经不是单个村镇或山道，而是：

- 五方区域
- 多书线地标
- 势力分布
- 跨区域剧情
- 地图状态变化
- 人物与事件随剧情推进迁移

现有地图更像临时功能测试场，规模感和承载能力都不够。它可以验证系统能跑，但还不能作为后续剧情内容持续投放的基础。

所以下一阶段建议把项目推进到“世界地图与剧情生产管线”的阶段。需求可以提得大一些，分批实现即可。

## 总目标

下一阶段希望搭出一套“大地图 + 地标数据 + 书线状态 + 势力变化”的框架。

这不是要求一次性做完最终大地图，也不是要求马上完成正式美术，而是先做出一个方向正确、后续能持续扩展的世界承载层。

这套框架需要让剧情设计可以稳定落地：

- 我这边可以继续整理区域、地标、人物、书线、事件、势力状态。
- 底层可以把这些内容接入地图、任务、事件、对话、存档系统。
- 后续新增地标、书线、势力变化时，不需要每次都大改底层。

## 第一批：世界地图 Demo

第一批先做一个真正有世界感的大地图 demo。

地图至少要能表现五个区域：

- 中原腹地
- 江南/金陵
- 北地/燕京
- 燕云/辽东/塞外
- 西域/雪山/边疆

地图上先摆一批核心地标，用来验证后续内容能否承载。

可以优先放这些：

- 长安
- 洛阳
- 武当山
- 少林寺
- 氓山
- 金刀寨
- 苏州
- 太湖
- 北京/京师
- 土木堡
- 辽东
- 天山
- 蛇岛

这一批的重点不是最终美术，而是让人一眼看到：

- 这是一个大世界，不是几个小场景拼接。
- 五方区域有清楚的空间关系。
- 地标之间能形成路线和区域层级。
- 后续几十个地标可以继续往上加。
- 地图能够成为剧情和书线的入口。

美术可以先用临时底图、区域色块、地标图标、路线线条表达，但最好先摆脱“小像素块临时地图”的感觉。

## 第二批：地标数据系统

地标不要只是地图上的一个图标，而应该成为剧情数据的挂载点。

每个地标最好能配置：

- id
- 显示名
- 所属区域
- 所属书线
- 所属势力
- 当前状态
- 相关人物
- 可触发事件
- 可进入场景
- 解锁条件
- 传闻线索
- 剧情备注

例如“天山”不应该只是一个传送点，而是一个跨书线枢纽：

```text
id: tianshan
显示名: 天山
区域: 西域/雪山/边疆
书线: 白发魔女传、七剑下天山、云海玉弓缘
势力: 天山派
功能: 武学传承、跨书线枢纽、人物归宿地
状态: 未发现 / 可前往 / 门派封山 / 剧情开放
```

例如“北京/京师”也不应该固定成单一城市，而要能根据剧情表现不同状态：

```text
id: capital_beijing
显示名: 北京/京师
区域: 北地/燕京
书线: 萍踪侠影录、白发魔女传、七剑下天山、云海玉弓缘
势力: 明廷 / 北清 / 朝廷鹰犬
功能: 政治中心、潜入、救援、刺杀、朝廷事件
状态: 明都 / 清都 / 敌占 / 戒严 / 可潜入 / 已解放
```

这样后续写剧情时，就可以把地标当成稳定的数据节点，而不是每次临时写死一段逻辑。

## 第三批：书线推进框架

每条书线不要一开始就做完整剧情，但系统需要先支持“书线状态”。

每条书线可以有类似状态：

- 未开启
- 听闻传闻
- 接触核心人物
- 进入主线冲突
- 关键节点临近
- 原局结局
- 改命结局
- 圆满结局

例如《白发魔女传》《七剑下天山》《云海玉弓缘》这些线，未来都可以按同一套结构推进。

书线状态需要能影响：

- 地标是否可见
- 地标是否可进入
- 人物出现位置
- 事件是否触发
- 区域是否封锁
- 路线是否开放
- 势力状态是否变化
- 对话分支是否变化

这样地图、人物、任务和剧情才能联动起来。

## 第四批：势力与区域变化

大地图需要能表现势力变化，否则世界会比较静态。

后续至少希望支持这些变化：

- 北清势力扩张或被压制。
- 金国前线推进或退兵。
- 义军据点被围、转移、壮大。
- 群侠盟建立后出现自己的据点。
- 某些地标从敌占变成可进入。
- 某些城市因为剧情进入戒严、封锁、搜捕状态。
- 某些路线因为剧情开放或关闭。

主要势力可以先包括：

- 中原正朔
- 北清
- 金国
- 义军
- 天山派
- 武林正派
- 朝廷清流
- 朝廷奸党
- 群侠盟
- 独立边疆势力

这些势力不需要一开始做复杂数值，但至少要能在地图上表达归属和状态。

例如：

```text
金刀寨
初始状态: 义军据点
中期状态: 被围困
破局后状态: 群侠盟重要据点
失败状态: 被攻破
```

```text
燕京
初始状态: 北清核心区
潜入阶段: 戒严
义军推进后: 外围动荡
关键战后: 部分区域开放
```

这套东西可以承接剧情里的“江湖势能”：

- 实力
- 羁绊
- 声望
- 时机
- 阵营资源

玩家不是只在任务列表里推进剧情，而是能看到世界状态发生变化。

## 第五批：地图美术与交互升级

美术不需要第一时间最终化，但方向要对。

希望大地图逐步具备：

- 清晰的五方区域底图
- 不同类型的地标图标
- 不同类型的路线
- 势力范围或势力标记
- 鼠标悬停提示
- 点击后的地标信息面板
- 地标状态变化表现
- 已发现与未发现区分
- 可进入与不可进入区分

地标图标可以按类型区分：

- 城池
- 山门
- 关隘
- 战场
- 岛屿
- 草原
- 雪山
- 皇宫
- 山寨
- 水寨
- 镖局
- 秘境

路线也可以按类型区分：

- 官道
- 山路
- 水路
- 边关通道
- 潜入路线
- 传闻路线
- 剧情路线

现在不要求最终资源，但希望先避免地图看起来太小、太临时、太像像素块测试场。

这不是单纯审美问题，而是生产信心问题。地图如果没有世界感，我这边很难判断后续地标和剧情到底能不能落进去。

## 可以直接发给同伴的版本

现在 MVP 已经把移动、任务、对话、战斗、存档这些基础闭环跑通了，这一阶段的价值很明确。

但下一阶段如果继续往现有小地图里塞剧情，我这边会很难推进。因为我现在整理的内容已经不是单个村镇或山道，而是“五方区域 + 多书线地标 + 势力分布 + 跨区域剧情 + 地图状态变化”。现有地图太像临时功能测试场，规模感和承载能力都不够，我没法基于它继续稳定填数据。

所以我想下一步先把项目推进到“世界地图与剧情生产管线”的阶段。这个需求可以做得比较大，分批实现就行。

第一批先做一个真正有世界感的大地图 demo，至少能表现中原腹地、江南/金陵、北地/燕京、燕云/辽东/塞外、西域/雪山/边疆这五个区域。地图上先摆一批核心地标，比如长安、洛阳、武当、少林、金刀寨、苏州、太湖、北京/京师、土木堡、辽东、天山、蛇岛等。重点不是最终美术，而是让我看到这个世界确实能承载后续几十个地标。

第二批希望地标完全数据化。每个地标不只是一个图标，而是能挂区域、书线、势力、人物、事件、传闻、解锁条件、跳转场景、当前状态。比如天山能同时关联白发、七剑、云海几条线；北京/京师能根据剧情表现为明都、清都、敌占、潜入、戒严等状态。

第三批做书线推进框架。每条书线可以有未开启、传闻、接触核心人物、进入主线冲突、关键节点、原局、改命、圆满这些状态。地图地标、人物位置、事件开放都能跟书线状态联动。

第四批做势力和区域变化。北清、金国、中原正朔、义军、天山派、群侠盟这些势力最好能在地图上有表现，并且能随着剧情推进发生变化：封锁、敌占、解放、开放路线、出现新据点、触发追捕或救援事件。

第五批再逐步升级地图美术和交互。现在不要求最终资源，但希望先摆脱“小像素块临时地图”的感觉。可以先用临时底图、区域色块、地标图标、路线线条、信息面板搭出方向。只要这套结构跑通，我这边就可以开始把地标表和剧情架构持续往里填。

简单说，下一阶段我希望我们不要只继续做小功能切片，而是先做一个“大地图 + 地标数据 + 书线状态 + 势力变化”的框架。它不需要一口气完整，但方向要对。否则剧情越写越多，后面会发现底层承接不了，还得返工。
